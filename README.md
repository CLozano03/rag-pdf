# RAG PDF Q&A

Sistema de resumen y preguntas sobre documentos PDF usando RAG.

## Instalación rápida

```bash
# Instalar dependencias con uv
uv sync

# Configurar API key
export OPENAI_API_KEY="sk-..."

# Ejecutar
uv run python main.py tu_documento.pdf
```

## Requisitos
- Python 3.11+
- [uv](https://docs.astral.sh/uv/) instalado
